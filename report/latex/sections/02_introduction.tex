\section{Introduction}
\label{sec:introduction}

Combinatorial game AI historically coupled explicit game-tree search with spatial reinforcement learning \parencite{silver2018general,stockfish2023}, relying on hardcoded rule engines and lookahead simulation. In contrast, causal transformers \parencite{vaswani2017attention} raise an important question: \textit{can a neural network induce chess rules, tactics, and positional strategy purely from next-token sequence modeling, without search trees or rule engines?} Sequence-based game models \parencite{Toshniwal2021ChessAA,li2023emergent,ruoss2024amortized} demonstrate that autoregression can implicitly track board state. However, existing implementations suffer from high latency, large memory footprints, and move hallucinations over extended games. Standard models with absolute position embeddings also struggle to generalize across long tactical sequences.

For deployment, this project adopts modern approaches, using PyTorch~2.3 \parencite{paszke2019pytorch} and GGUF quantization \parencite{gerganov2023llamacpp} in place of legacy static-graph frameworks.

\subsection{Aims and Objectives}
\label{sec:intro_aims}
This research designs, implements, empirically validates, and critically appraises \textbf{Nebium}, a causal transformer for self-supervised move prediction in chess. This study addresses five core objectives:
\begin{enumerate}
    \item Construct an automated pipeline converting PGN archives into UCI sequences tokenized with a 2,056-token BPE vocabulary.
    \item Assemble a causal transformer integrating Rotary Position Embeddings (RoPE) \parencite{su2024roformer}, SwiGLU activations \parencite{shazeer2020glu}, and RMSNorm pre-normalization \parencite{zhang2019root}.
    \item Train Nebium across parameter scales to evaluate loss convergence, perplexity, top-$k$ accuracy, and unconstrained move legality.
    \item Evaluate next-token prediction accuracy, validation perplexity, move legality across horizons, and edge serving efficiency.
    \item Analyze architectural failure modes, coordinate drift over deep game horizons, and ethical and compute implications.
\end{enumerate}

\subsection{Summary of Dataset and Key Achievements}
\label{sec:intro_achievements}
This study uses 245,293 standard competitive games from the Lichess Open Database (January--February 2013), pre-tokenized into UCI coordinate strings and encoded via a 2,056-token BPE vocabulary.

The primary achievements of Nebium include:
\begin{itemize}
    \item Across the model family, Nebium-Small (117M) achieved a validation loss of 2.727 nats (perplexity 15.30) with 100\% opening legality; Nebium-Medium (345M) reached 2.376 nats (perplexity 10.76) and 36.4\% top-1 move accuracy (70.5\% top-5); Nebium-Large (762M, 3 epochs) achieved 6.071 nats loss and 80.0\% legality within its early training trajectory.
    \item Unconstrained generative rollouts demonstrate that board-level move syntax is acquired early in training, reaching 80.0\% legal move generation on Large by epoch 3 and 100\% opening legality on Small at epoch 20.
    \item Dynamic legal move masking eliminates invalid coordinate emissions during deployment by projecting transformer output distributions over valid board moves at each ply.
    \item 4-bit GGUF quantization compresses the Nebium-Small checkpoint to 88.1 MB, allowing lightweight inference execution on standard consumer hardware.
\end{itemize}
