\section{Experimental Results and Empirical Analysis}
\label{sec:experiments}

\subsection{Training Configuration and Parameter Settings}
\label{sec:exp_setup}
Experiments were conducted in PyTorch 2.3 with native FP16 automatic mixed precision (\texttt{torch.cuda.amp}) on an NVIDIA RTX 4090 GPU (24 GB VRAM). Training hyperparameters were determined via empirical grid search informed by transformer scaling literature \parencite{loshchilov2019decoupled,touvron2023llama,hoffmann2022training}:
\begin{itemize}
    \item \textbf{Decoupled Weight Decay Optimizer (AdamW)}: Configured with $\beta_1 = 0.90$, $\beta_2 = 0.95$, and $\epsilon = 10^{-8}$. Our grid search over $\beta_2 \in \{0.95, 0.98, 0.999\}$ revealed that $\beta_2 = 0.95$ adapts significantly faster to discrete chess token transitions by reducing momentum lag. A decoupled weight decay $\lambda = 0.1$ was applied strictly to 2D projection and feed-forward matrices; 1D parameters (RMSNorm gain vectors $\boldsymbol{\gamma}$) were masked from decay to preserve scaling capacity.
    \item \textbf{Learning Rate Schedule}: A peak learning rate $\eta_{\text{max}} = 3.0 \times 10^{-4}$ was scheduled with 1,000 linear warmup steps to stabilize early query-key projections, followed by Cosine Annealing decaying to $\eta_{\text{min}} = 3.0 \times 10^{-5}$ across 20 epochs.
    \item \textbf{Batch Throughput and Gradient Clipping}: We utilized effective batch size $B = 32$ over sequence window $T = 512$ (16,384 tokens/step), staying within GPU L2 cache residency. Global gradient norm clipping was enforced at $\|\mathbf{g}\|_2 \le 1.0$ to mitigate gradient spikes from rare tactical blunders.
\end{itemize}

\label{sec:exp_dynamics}
The empirical optimization progression across 20 epochs is illustrated in Figure~\ref{fig:training_dynamics}. Dynamics exhibit three distinct learning phases: Phase~I (Epochs 1--4: Opening Theory Acquisition), where cross-entropy loss drops 54.5\% ($5.105 \to 2.32$, perplexity $141.8 \to 10.17$); Phase~II (Epochs 5--12: Tactical Pattern Formation), where convergence moderates as attention heads learn piece pins and coordinate relations; and Phase~III (Epochs 13--20: Endgame Fine-Tuning), reaching asymptotic stability at validation loss 1.884 and perplexity 6.55. \subsection{Centipawn Blunder Analysis via Stockfish}
\label{sec:exp_blunder}
The strategic quality of moves was evaluated by measuring the Centipawn Drop ($\Delta \text{CP}$) relative to the optimal engine move $m^*$:
\begin{equation}
    \Delta \text{CP} = \text{Eval}(m^*) - \text{Eval}(m_{\text{model}})
\end{equation}
A move was categorized as an Inaccuracy if $50 \le \Delta \text{CP} < 100$, a Mistake if $100 \le \Delta \text{CP} < 200$, and a Blunder if $\Delta \text{CP} \ge 200$ ($\ge 2.0$ pawns).

\begin{figure}[H]
  \centering
  \includegraphics[width=0.80\linewidth]{figures/blunder_distribution.pdf}
  \caption[Stockfish 16 Centipawn Loss Distribution]{Stockfish 16 (Depth 10) centipawn evaluation loss ($\Delta \text{CP}$) probability densities across game horizons. The hatched region demarcates the critical blunder zone ($\Delta \text{CP} \ge 200$), accounting for only 6.2\% of aggregate moves.}
  \label{fig:blunder_distribution}
\end{figure}

As shown in Figure~\ref{fig:blunder_distribution}, $\Delta \text{CP}$ exhibits high positional stability during opening and middlegame play, with median errors below 25 CP (mean loss of 18.2 CP and 37.8 CP, respectively). The endgame exhibits a heavy right tail (mean loss 73.9 CP) because sparse positions frequently hinge upon a single critical square. Across the complete corpus, critical blunders occurred in only 6.2\% of moves, verifying robust tactical stability.

\subsection{Inference Latency, Throughput, and Quantization}
\label{sec:exp_latency}
Real-time desktop integration requires sub-50 ms move generation. As critically appraised in Section~\ref{sec:tools_deployment}, modern edge deployment leverages GGUF 4-bit quantization (\texttt{Q4\_K\_M}) to eliminate Python interpreter overhead and allow seamless CPU execution. We benchmarked per-move latency across precision profiles on an NVIDIA RTX 4090 and consumer CPU.
